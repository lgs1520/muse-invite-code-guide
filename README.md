# Muse Invite Code Guide

How Muse invite codes work, how to redeem one, where to find your own code, and what to do when a code doesn't work.

**Need a code right now?** The community pool keeps a live list you can claim from for free:
👉 https://muse-invite-pool.pages.dev/

## How invite codes work

- Muse launched its invite program on September 16, 2026.
- Every Muse account has its own invite code.
- When a new user redeems your code, **you** receive 1 billion tokens. A code can be filled up to 30 times (30B total).
- The person redeeming gets access by signing up — the reward goes to the code's owner.

## The two rules that trip everyone up

1. **48-hour window.** You can only redeem a code within 48 hours of registering your account. Miss the window and the account can never redeem one.
2. **Once per account, ever.** Each account can redeem one code in its lifetime. Pick a code that actually works before you use yours up.

## How to redeem a code

- **Mobile app:** Settings → Redeem token
- **Web:** Settings → General → Usage → Redeem invite code

Step-by-step with screenshots described: [How to redeem a Muse invite code](https://muse-invite-pool.pages.dev/redeem/)

## Where to find your own code

Open Muse and check the Earn / Invite section — your code and how many uses you have left are shown there. Full walkthrough: [Find and share your Muse invite code](https://muse-invite-pool.pages.dev/find-your-code/)

Got a code that isn't full yet? You can register it with the pool so other new users can fill it for you: [Fill up your code](https://muse-invite-pool.pages.dev/fill-up/)

## Code not working?

The usual causes: the code is already full (30/30), your account is past the 48-hour window, or your account already redeemed a code once. There is no official way to check a code without trying it — the redeem result inside the app is the only verdict.

Full troubleshooting list: [Muse invite code not working](https://muse-invite-pool.pages.dev/not-working/)

If a pooled code fails, just claim a different one — codes that keep failing get flagged and paused automatically.

## Honesty note

The pool hands out codes shared by their owners. A code being listed does not guarantee it still has room — nobody can verify that in advance. If one fails, swap it for another; that feedback is exactly what keeps the dead ones out.
