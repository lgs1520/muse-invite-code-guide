## How invite codes work

- Meta's Muse invite program was announced on September 16, 2026.
- Every Muse account has its own invite code.
- A successful redemption pays **1 billion tokens to both sides**. The bonus pool never expires.
- A code stops working once it reaches its redemption cap (20–30, see the short answer above).

## What 1 billion tokens is worth

Weekly usage quotas by plan (as shown in the Muse app; the app prevails):

| Plan | Weekly quota |
|---|---|
| Free | ~100M tokens / week |
| Power ($20/mo) | ~500M tokens / week |
| Maximum ($100/mo) | ~3B tokens / week |

So one invite bonus (1B, never expires) ≈ **10 weeks of the Free plan's quota, or 2 weeks of Power**. Your weekly quota is spent first; the bonus pool is used after.

## The two rules that trip everyone up

1. **48-hour window.** You can only redeem a code within 48 hours of registering your account. Miss the window and the account can never redeem one.
2. **Once per account, ever.** Each account can redeem one code in its lifetime. Pick a code that actually works before you use yours up.

## How to redeem a code

- **Mobile app:** Settings → Redeem invite code
- **Web:** Settings → General → Usage → Redeem invite code

## Code not working?

The usual causes: the code already hit its cap, your account is past the 48-hour window, or your account already redeemed a code once. There is no official way to check a code without trying it — the redeem result inside the app is the only verdict.

Full troubleshooting list: [Muse invite code not working](https://muse300.com/not-working/)

If a pooled code fails, just claim a different one — codes that keep failing get flagged and paused automatically.

**Is there a Muse invite code pool?**

**What is Muse by Meta?**
Muse is Meta's personal AI agent (launched September 2026): it runs tasks for you in a secure cloud computer, connects your apps, and remembers context across conversations. The invite codes above are for this Muse — not for any developer tool of a similar name.

**Are Muse invite codes legit?**
The mechanism is real and built into the app. A code itself is just a string — redeem it only inside Muse's own Settings, never on a third-party form, and never pay anyone for a code.
